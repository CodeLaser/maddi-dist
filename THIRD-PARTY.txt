maddi IDE plugins, daemon and MCP server: third-party components
================================================================

The maddi plugins for IntelliJ IDEA and Eclipse, and the maddi MCP server, bundle the maddi analysis daemon,
which runs in a JVM of its own. maddi itself is licensed under the Apache License, Version 2.0 (LICENSE,
NOTICE). The daemon, the plugins and the MCP server also ship the following third-party libraries, unmodified,
each under its own license.

Kept in step with the runtime class paths by the `checkThirdPartyNotices` tasks of maddi-ide-daemon and
maddi-mcp, which fail the build when a bundled library is missing here.
