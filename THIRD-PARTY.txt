maddi IDE plugins and daemon: third-party components
=====================================================

The maddi plugins for IntelliJ IDEA and Eclipse bundle the maddi analysis daemon, which runs in a JVM of its
own. maddi itself is licensed under the Apache License, Version 2.0 (LICENSE, NOTICE). The daemon and the
plugins also ship the following third-party libraries, unmodified, each under its own license.

Kept in step with the daemon's runtime class path by the `checkThirdPartyNotices` task of maddi-ide-daemon,
which fails the build when a bundled library is missing here.
